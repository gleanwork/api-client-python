# Search

## Overview

### Available Operations

* [query](#query) - Search

## query

Execute a search query and retrieve ranked results. This is the data retrieval variant of the search API and returns only results and pagination state.


### Example Usage

<!-- UsageSnippet language="python" operationID="platform-search" method="post" path="/api/search" -->
```python
from glean.api_client import Glean
import os


with Glean(
    api_token=os.getenv("GLEAN_API_TOKEN", ""),
) as glean:

    res = glean.search.query(query="quarterly planning 2026", page_size=10, datasources=[
        "confluence",
        "google_drive",
    ], filters=[
        {
            "field": "type",
            "values": [
                "spreadsheet",
                "presentation",
            ],
        },
    ])

    # Handle response
    print(res)

```
