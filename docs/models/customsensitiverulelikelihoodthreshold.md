# CustomSensitiveRuleLikelihoodThreshold

Likelihood threshold for BUILT_IN infotypes (e.g., LIKELY, VERY_LIKELY). Only applicable for BUILT_IN type.


## Values

| Name            | Value           |
| --------------- | --------------- |
| `LIKELY`        | LIKELY          |
| `VERY_LIKELY`   | VERY_LIKELY     |
| `POSSIBLE`      | POSSIBLE        |
| `UNLIKELY`      | UNLIKELY        |
| `VERY_UNLIKELY` | VERY_UNLIKELY   |
